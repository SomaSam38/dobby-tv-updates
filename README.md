# Dobby TV — family downloads

Dobby TV is a personal Samsung TV player for Sam, family and friends. It includes no channels or provider accounts; each person uses their own playlist details.

[Download the Mac installer and updater 1.1.0](https://github.com/SomaSam38/dobby-tv-updates/releases/download/installer-1.1.0/Dobby-TV-Installer-Mac-1.1.0.zip)

Apple silicon or Intel, macOS 13+. Move the app to Applications and follow START HERE. No AI, Codex, Terminal, system Python or Tizen Studio is needed. Samsung Developer Mode and a Samsung browser sign-in are part of the initial TV setup. The Mac can be switched off for normal TV viewing.

Enable automatic checks in the Mac app to check and download releases while the Mac is awake. Installation asks you to confirm the television is free, then saves current data, updates in place, and checks the saved records again after a cold restart. Keep the TV on and the Mac on the same home network. This is not a TV-browser or Samsung Store installer. Current support is for Dobby-only TVs; a TV with Casa needs a coordinated household backup.

Viewing data, accounts, encrypted backups and private signing certificates stay on the owner's TV/Mac. They are not uploaded here. Keep original certificates for future updates. Never uninstall Dobby or replace its signing certificates to work around an update error.

The Mac app is Developer ID signed but not notarised. Included instructions explain the one-time macOS Open Anyway path for this original download. Do not disable Mac security settings.

TV build 1.9.68 is based on [OpenIPTV](https://github.com/shayanline/OpenIPTV). Its MIT licence and all third-party notices are included in the app package. Release metadata is Ed25519 signed; a download server cannot authorise changed code without the separate release signing key. Future code is deliberately tested and published by Sam; the updater does not generate releases itself.
